# 데모 자료 (가상)

데모 봇(@sagak_demo_bot)에 보내 볼 수 있는 가상 상담 자료입니다. 이름·연락처·업체는 모두 가상입니다.

| 파일 | 보내는 법 | 보이는 것 |
|---|---|---|
| `kakao-chat.txt` | 파일로 보내기 (캡션 없이도 됨 — 대화 속 이름·연락처를 씀) | 채팅 내보내기 기록, 레스토랑 프로포즈, 12/24 20:00 확정 일시, 레터링 케이크 옵션 3만 원, 견과류 금지 특이사항, 예약금 20만 원 |
| `call-recording.m4a` | 녹음 파일로 보내기, 캡션 `강민준 / 010-0000-7003` | 녹음 전사(화자·시각), 정원패키지 종류를 몰라 '희망 상품' 확인 필요와 질문, 촬영 옵션 15만 원, 근거 문장별 녹음 클립 |

`call-recording.m4a`는 Mac에서 `bash demo/make-call-audio.sh`로 만듭니다(`call-script.txt`를 두 목소리로 읽음).
