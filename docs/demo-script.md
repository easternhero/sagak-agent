# 데모 녹화 대본

데모 봇(프로필 `sagak-demo`)과 공개 데모 노션(가상 업체 '설렘 이벤트')으로 찍습니다. 모든 이름·번호는 가상입니다.
화면 왼쪽에 텔레그램(데모 봇), 오른쪽에 데모 노션을 띄워 둡니다. 2~3분.

## 1. 녹음으로 새 상담 기록 (약 60초)

휴대폰 음성 메모로 두 사람이 통화하듯 읽어 녹음하고, 봇에 파일과 캡션을 보냅니다.

캡션: `한지우 / 010-0000-7001`

> 상담: 네, 설렘이벤트입니다.
> 고객: 안녕하세요, 갤러리 프로포즈 보고 연락드렸어요. 12월 5일 토요일 저녁 7시에 하고 싶어요.
> 상담: 네 가능해요. 인원이나 추가로 원하시는 건 있으세요?
> 고객: 장미 50송이 추가하고 싶고요, 사진 촬영도요. 서프라이즈라서 여자친구한테는 절대 연락하시면 안 돼요.
> 상담: 알겠습니다. 예약금 30만 원 입금되시면 확정해 드릴게요.

보여 줄 것: 봇 답장(기록 결과·확인 필요·노션 링크) → 노션 이벤트 페이지(희망 일시 12/5 19:00, 상품 갤러리패키지, 특이사항 '연락 금지', 지도 링크) → 상담 이력의 근거 문장 밑 녹음 클립 재생 → 전사 원문 토글.

## 2. 정보가 빠진 메모 → 물어볼 것 (약 30초)

봇에 텍스트로 보냅니다.

```
한지우 / 010-0000-7001
2차 통화 메모: 장소를 레스토랑으로 바꿀 수 있는지 물어봄. 날짜는 아직 고민 중이라고 함.
```

보여 줄 것: 같은 고객·이벤트의 2차 상담으로 이어짐, 바뀐 내용은 '기존 정보와 다름'으로만 표시(덮어쓰지 않음), 고객에게 물어볼 것.

## 3. 같은 연락처, 다른 이름 → 사람 확인 (약 30초)

```
한지수 / 010-0000-7001
예약 날짜 다시 확인하고 싶다고 전화 옴
```

보여 줄 것: 봇이 "같은 고객인가요?"라고 묻고 답하기 전에는 연결하지 않음 → "같은 사람이야"라고 답하면 연결.

## 4. 업무와 상관없는 요청 → 거절 (약 10초)

```
오늘 서울 날씨 어때?
```

보여 줄 것: 한 문장으로 거절하고 할 수 있는 일을 안내.

## 5. 예약금 입금 → 자동 정리 (약 20초)

노션에서 한지우 이벤트의 결제 상태를 '예약금 입금'으로 바꾸고, 아무 상담이나 하나 더 기록합니다.

보여 줄 것: 확정 일시가 채워지고 이벤트 상태가 '이벤트진행예정'으로 바뀜, 캘린더에 표시.

## 6. 끝나면

데모 프로필은 `SAGAK_DEMO=1`이라 010-0000 번호에도 [테스트] 표시를 붙이지 않습니다. 녹화 기록은 공개 데모에 그대로 둡니다.
