# 봇 테스트 시나리오

텔레그램 봇으로 처음부터 끝까지 확인하는 시나리오입니다. 실제 고객사 노션에 기록되지만 **테스트 기록**으로 표시되고, 끝나면 한꺼번에 지웁니다 (D44).

- 테스트 기록 = 성함이 `[테스트]`로 시작하거나 연락처가 `010-0000-`인 고객. 모든 값은 가상입니다.
- 테스트 기록을 할 때 도는 자동 점검(sweep)은 **테스트 이벤트만** 건드립니다. 실제 이벤트는 그대로입니다.
- 시작 전에 봇에 `/new`를 보내 최신 스킬을 쓰게 합니다.
- 끝나면 봇에 `테스트 정리`라고 보냅니다 → 목록 확인 → "응" → 휴지통으로 (T9).

결과 확인 표시: ✅ 기대대로 / ❌ 다름(무엇이 달랐는지 메모)

---

## T1. 새 고객 · 대화 붙여넣기

**보낼 메시지** (한 메시지로)

```
[테스트] 박서준 / 010-0000-0001
2026-11-08 14:02, 박서준 : 호텔 프로포즈 문의드려요
2026-11-08 14:03, 예시이벤트 : 네 고객님, 희망 날짜 있으실까요?
2026-11-08 14:05, 박서준 : 12월 12일 토요일 저녁 7시요. 장소는 용산 그랜드호텔이에요
2026-11-08 14:06, 예시이벤트 : 가능합니다. 예약금 30만원 안내드려요. 입금되면 확정됩니다
```

**확인**
- [ ] 고객 `[테스트] 박서준`, 이벤트, 1차 상담이 생김
- [ ] 희망 이벤트가 호텔 상품으로 맞춰지고, 이벤트 테마는 **프로포즈(자동)**
- [ ] 희망 일시 12/12 19:00, 예약금액 300,000원, 확인 필요에 `예약금` (예산 표시는 없음)
- [ ] 입력 방식 `대화`
- [ ] 지도 링크에 그랜드호텔 검색 링크

## T2. 긴 대화 파일 · 원문 끝까지

**보낼 것**: `tests/fixtures/bot/long-chat.txt` 파일 + 캡션 `[테스트] 최하늘 / 010-0000-0002`

**확인**
- [ ] 상담 이력 페이지에 `전사 원문 (167줄)` 접기 제목 → 펼치면 첫 줄 "최하늘 님과의 상담"부터 마지막 줄 "마지막 줄 확인용 문장입니다"까지 모두 있음
- [ ] "(분량이 많아 이하 생략)"이 없음
- [ ] 특이사항에 "상대에게 연락 금지(서프라이즈)"
- [ ] 예약금액 300,000원

## T3. 후속 상담 · 이전 상담으로 빈 칸 보충

**준비**: 노션에서 T1 이벤트의 `희망 장소`와 `지도 링크`를 지웁니다(비워 둠).

**보낼 메시지**

```
[테스트] 박서준 / 010-0000-0001
2026-11-09 10:00, 박서준 : 혹시 풍선 장식도 추가할 수 있을까요?
2026-11-09 10:02, 예시이벤트 : 네 풍선 옵션 5만원입니다
```

**확인**
- [ ] 같은 이벤트에 2차 상담으로 붙음
- [ ] 비워 둔 `희망 장소`가 이전 상담 내용(용산 그랜드호텔)으로 다시 채워짐
- [ ] 근거에 `이전 상담 11/08: …` 줄
- [ ] 옵션 내역에 풍선, 옵션 가격 50,000

## T4. 예약금 입금 → 확정 일시·진행예정 (자동 점검)

**준비**: 노션에서 T1 이벤트의 `결제 상태`를 **예약금 입금**으로 바꿉니다. `확정 일시`는 비워 둡니다.

**보낼 것**: 아무 테스트 기록 하나 (예: T5 메시지)

**확인**
- [ ] 답장 끝에 `🧹 다른 이벤트도 정리했어요` + T1 이벤트 한 줄
- [ ] T1 이벤트 확정 일시 = 12/12 19:00, 이벤트 상태 = 이벤트진행예정
- [ ] T1 이벤트 본문에 `자동 정리 (MM/DD HH:MM)` 항목
- [ ] 실제 고객 이벤트는 바뀌지 않음

## T5. 00:00 알림

**준비**: 노션에서 T2 이벤트의 `희망 일시`를 시각 00:00으로 바꾸고, `희망 일시(원문)`에 "12월 5일 저녁 7시"를 적어 둡니다.

**보낼 메시지**

```
[테스트] 정유나 / 010-0000-0003
2026-11-09 11:00, 정유나 : 생일 이벤트도 하시나요? 날짜는 아직 미정이에요
```

**확인**
- [ ] 답장에 `🔎 확인해 주세요` + T2 이벤트 "희망 일시가 00:00인데 원문에 시각이 있어요: '저녁 7시'"
- [ ] T2 이벤트는 고치지 않음
- [ ] 정유나 이벤트: 테마 생일/기념일, 희망 일시 비어 있고 확인 필요 `희망 일시`

## T6. 확정 일시 지남 → 완료

**준비**: 노션에서 T5(정유나) 이벤트의 `확정 일시`를 **어제**로, `이벤트 상태`를 **이벤트진행예정**으로 바꿉니다.

**보낼 것**: 아무 테스트 기록 하나 (예: T7 메시지)

**확인**
- [ ] 답장 `🧹`에 정유나 이벤트 "이벤트진행예정 → 이벤트완료"
- [ ] 이벤트 상태 = 이벤트완료

## T7. 같은 번호 · 다른 이름 → 고객 연결 필요

**보낼 메시지**

```
[테스트] 박서진 / 010-0000-0001
2026-11-09 12:00, 박서진 : 오빠 대신 연락드려요. 시간 30분 늦출 수 있을까요?
```

**확인**
- [ ] 검토 상태 `고객 연결 필요`, 답장에 후보(박서준)와 "같은 고객인가요?"
- [ ] "같은 고객이야"라고 답하면 박서준 이벤트에 3차 상담으로 붙음 (고객 이름은 그대로 박서준)

## T8. 녹음 · 근거 클립 (선택)

**준비**
1. 프로필 `.env`에 `SAGAK_AUDIO_CLIPS=1`을 넣고 봇에 `/restart` (클립을 켜야 할 때만, D43)
2. 맥 터미널에서 테스트 녹음 만들기:
   ```
   cd ~/work/sagak && say -v Yuna -f tests/fixtures/bot/voice-script.txt -o /tmp/sagak-test.aiff && afconvert /tmp/sagak-test.aiff ~/Desktop/sagak-test.m4a -d aac -f m4af
   ```

**보낼 것**: `sagak-test.m4a` 파일 + 캡션 `[테스트] 홍길동 / 010-0000-0004`

**확인**
- [ ] 입력 방식 `녹음`, 전사 원문이 `[mm:ss]` 줄로 끝까지
- [ ] 근거 줄(희망 일시·예약금·특이사항 등) 밑에 재생 버튼, 누르면 그 문장 부분이 나옴
- [ ] 특이사항에 생화 제외(알레르기)
- [ ] 클립을 끈 상태(`SAGAK_AUDIO_CLIPS` 없음)에서는 재생 버튼 없이 기록만

## T9. 테스트 정리

**보낼 메시지**: `테스트 정리`

**확인**
- [ ] 봇이 지울 목록(고객·이벤트·상담)을 먼저 보여 주고 확인을 물음
- [ ] "응" → 테스트 기록이 모두 노션 휴지통으로, 실제 고객 기록은 그대로
- [ ] 노션 휴지통에서 되살릴 수 있음
