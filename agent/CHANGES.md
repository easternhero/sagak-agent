# 사각사각 변경 안내

봇 사용자에게 보내는 안내. **위가 최신**, 한 줄에 하나, 사용자 말투로 짧게.
봇 전체 재시작이 필요한 변경(설정·키)은 줄 끝에 `[restart]`를 붙인다 → 관리자에게만 [/restart] 버튼.

보내기 (개발자 PC에서): `PYTHONPATH=src python3 -m sagak announce` (미리 보기: `--dry-run`)
화면으로 보내기 (개발자 PC에서): `PYTHONPATH=src python3 -m sagak console` → 브라우저에서 문구 확인·편집 후 ① 관리자에게 보내 확인 → ② 직원에게 보내기. 명령으로는 `announce --to admin`, `announce --to others`. 보낸 위치는 프로필 폴더 `sagak_announced.json`.

## 2026-11-08
- 기록할 때마다 다른 이벤트도 점검해요: 예약금이 들어온 건은 확정 일시를 희망 일시로 채우고 ‘이벤트진행예정’으로, 확정 일시가 지난 건은 ‘이벤트완료’로 바꾸고 답장에 알려 드려요
- 기록 전에 그 고객의 이전 상담을 다시 읽고, 노션에 빠져 있는 내용을 채워요
- 노션 칸 이름을 정리했어요: 날짜 → ‘확정 일시’, 예상 금액 → ‘고객 예산’, 총액 → ‘확정 금액’. ‘이달의 이벤트’ 캘린더는 이제 확정 일시 기준이에요
- ‘결제 방식’(온라인·카드·계좌이체)과 ‘결제 상태’(미입금·예약금 입금·완납)를 나눴어요
- 같은 고객인지 골라야 하는 상담은 ‘고객 연결 필요’로 표시돼요 (이전 ‘고객 확인 필요’)
- 고객이 예산을 말하지 않았다고 ‘확인 필요: 예산’을 붙이지 않아요
- 상품이 정해지면 이벤트 테마는 상품에 맞춰 자동으로 정해요
- 카톡·채팅 내보내기나 메모로 보낸 상담은 입력 방식 ‘대화’로 기록돼요

## 2026-11-07
- 통화에서 예약이 확정되면 이벤트 ‘날짜’(확정 일시)를 채워요. 아직 희망 단계면 희망 일시만 적어요
- 현장에서 챙길 것(서프라이즈 연락 금지, 호텔 사전 등록 등)을 이벤트 ‘특이사항’에 덧붙여요
- 인사말 등으로 접수 브랜드가 분명하면 ‘제휴’를 채워요
- 이벤트에 ‘지도 링크’ 칸이 생겼어요. 네이버 지도 공유 링크를 같이 보내 주시면 그 링크를, 아니면 확인된 장소의 검색 링크를 넣어 드려요
- 날짜만 말씀하셨으면 희망 일시를 00:00으로 넣고 ‘확인 필요’로 표시해요
- 상담에서 안내한 예약금 금액을 이벤트 ‘예약금액’ 칸에 기록해요 (입금 확인은 직접)
- 성함 대신 호텔·회사 이름만 오면 성함을 다시 여쭤봐요. 관리 페이지처럼 `김민수(그랜드호텔)`로 적어도 괄호 밖만 성함으로 기록해요
- 연달아 보낸 파일·녹음을 중간에 끊지 않고 차례로 처리해요 [restart]
- 이메일이 없어도 성함·연락처만 있으면 바로 기록해요
- 상담 채팅 내보내기 파일(… 님과의 상담.txt)도 상담 내용으로 받아요. 같은 통화의 전사와 녹음은 하나로 기록해요
- 결제 이야기(카드 결제 희망, 예약금 안내 등)는 상담 내역에 남기고, 계좌·카드번호만 가려요
- 상담자를 직원 이름으로 맞춰 기록해요 (성 없이 이름만 와도 성까지)
- 블랙리스트(B) 고객 상담이면 ⚠️로 먼저 알려 드려요
- 손님이 안내 이름(갤러리·호텔 프로포즈 등)으로 말해도 관리 페이지 상품명으로 기록해요
- 희망 이벤트 상품 목록을 지금 판매 중인 상품으로 맞췄어요
- 회사·단체 정보가 있으면 고객 구분을 '기업', 없으면 '개인'으로 기록해요
